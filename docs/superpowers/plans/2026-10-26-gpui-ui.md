> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建 `crates/postium-ui`（GPUI 应用）：主窗口（侧栏/邮件列表/详情）、写信窗口（postium-editor）、设置+OAuth、同步事件桥、托盘、i18n/主题，功能对齐 Tauri 版。

**Architecture:** 标准 `gpui-kit 0.8` 纯原生 UI；服务层经计划 1 的 `Arc<CoreApi>` 进程内直调；tokio 异步通过全局 Runtime + `spawn_tokio` 桥接 gpui 的 smol 执行器（`JoinHandle` 可跨执行器 await）；同步进度事件经 smol channel 由 `cx.spawn` 消费；托盘用 `tray-icon` crate（菜单事件走 channel）。

**Tech Stack:** gpui-kit 0.8、postium-core、postium-editor、tray-icon 0.26、rfd 0.17、open 5、tokio、smol、serde_json

**Spec:** `docs/superpowers/specs/2026-10-26-gpui-migration-design.md`（计划 1 已完成 core/editor 地基）

- [ ] **Step 2: runtime.rs（tokio 桥，全局约束代码）**

```rust
//! tokio Runtime 全局单例 + 跨执行器桥。
//! gpui 的执行器是 smol；tokio 服务的 Future 通过 JoinHandle
//! （实现 Future + Send，可被任意执行器 await）桥接。

use std::sync::OnceLock;
use tokio::runtime::Runtime;

static RUNTIME: OnceLock<Runtime> = OnceLock::new();

pub fn runtime() -> &'static Runtime {
    RUNTIME.get_or_init(|| Runtime::new().expect("初始化 tokio runtime 失败"))
}

/// 在 tokio 上执行 `fut`，返回可被 gpui 执行器 await 的接收端。
pub fn spawn_tokio<F>(fut: F) -> smol::channel::Receiver<F::Output>
where
    F: std::future::Future + Send + 'static,
    F::Output: Send + 'static,
{
    let (tx, rx) = smol::channel::bounded(1);
    runtime().spawn(async move {
        let out = fut.await;
        let _ = tx.try_send(out);
    });
    rx
}
```

- [ ] **Step 3: main.rs（装配：数据目录 → CoreApi → 主窗口）**

```rust
mod app;
mod runtime;

use std::path::PathBuf;

pub fn resolve_data_dir() -> PathBuf {
    // 对齐 Tauri 版 src-tauri/src/lib.rs:resolve_data_dir
    if std::env::var("POSTIUM_E2E").ok().as_deref() == Some("1") {
        return PathBuf::from(
            std::env::var("POSTIUM_DATA_DIR").expect("POSTIUM_E2E=1 时必须设置 POSTIUM_DATA_DIR"),
        );
    }
    dirs::home_dir().expect("无法获取用户目录").join(".postium")
}

fn main() {
    postium_core::sys_log_init(); // 若 core 未导出则按 src-tauri/src/sys/log.rs 复制 setup_logging
    let data_dir = resolve_data_dir();
    let e2e = std::env::var("POSTIUM_E2E").ok().as_deref() == Some("1");
    let e2e_truth = std::env::var("POSTIUM_E2E_TRUTH").ok().as_deref() == Some("1");

    // 服务装配在 tokio 上完成后进入 UI
    let (api, sync_rx) = runtime::runtime()
        .block_on(async { postium_core::api::CoreApi::init(&data_dir, e2e, e2e_truth).await })
        .expect("核心服务初始化失败");

    gpui_kit::application()
        .with_assets(gpui_kit::assets::Assets)
        .run(move |cx| {
            gpui_kit::init(cx);
            postium_editor::init(cx);
            app::open_main_window(api.clone(), sync_rx, cx);
        });
}
```

（若 `postium_core` 无 `sys_log_init`，在 core 的 lib.rs 增加 `pub fn sys_log_init()` 包装 `sys::log::setup_logging`，一并提交。）
