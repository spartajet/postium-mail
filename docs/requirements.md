# Postium 功能需求文档

> AI 驱动的桌面邮件客户端  
> 版本：v0.1（基于原型分析）

---

## 一、项目概述

### 1.1 产品定位

Postium 是一款跨平台桌面邮件客户端，以 **AI 能力为核心差异点**，提供智能摘要、智能回复、AI 辅助写作、邮件翻译、任务提取、**自然语言指令操控邮箱**等功能，同时集成个人日程管理与自动化工作流，帮助用户高效处理邮件。

### 1.2 目标用户

- 日均处理大量邮件的职场人士
- 需要多账号统一管理的用户
- 希望借助 AI 提升邮件处理效率的用户

---

## 二、整体布局

应用采用**三栏式布局**：

```
┌─────────────┬──────────────┬──────────────────────┐
│   侧边栏     │   邮件列表    │      邮件详情         │
│  (260px)    │  (380px)     │    (剩余宽度)          │
│             │              │                      │
│  - Logo     │  - 搜索框    │  - 邮件头部           │
│  - 账号选择  │  - 工具栏    │  - AI 摘要卡片        │
│  - 写邮件   │  - 邮件条目  │  - 邮件正文           │
│  - 导航菜单  │              │  - 附件列表           │
│  - AI 分类  │              │  - AI 操作栏          │
│  - 储存占用  │              │                      │
└─────────────┴──────────────┴──────────────────────┘
```

特殊视图（日程、工作流、**AI 对话**）切换时，邮件列表和详情面板隐藏，替换为全宽视图。

**AI 对话框**也可通过悬浮按钮在任意视图下以侧边抽屉形式唤出，不打断当前操作。

## 三、功能模块详细需求

### 3.1 账号管理

#### 3.1.1 多账号支持

- 支持同时添加多个邮箱账号
- 支持的邮件服务商：
  - Gmail
  - Outlook / Hotmail
  - iCloud Mail
  - Yahoo Mail
  - 通用 IMAP / SMTP（自定义服务器）
- 账号切换通过侧边栏顶部下拉选择器实现
- 每个账号可设置：
  - 账号名称（显示名）
  - 邮箱地址
  - 颜色标签（用于在 UI 中区分账号）
  - 服务商类型
- 系统根据服务商自动配置 IMAP / SMTP 参数
- 账号选择器显示：头像首字母 + 账号名 + 邮箱地址 + 未读数

---

### 3.2 邮件列表

#### 3.2.1 侧边栏导航

侧边栏包含以下导航区域：

**内置文件夹：**

| 文件夹 | 说明 |
|--------|------|
| 收件箱 | 显示未读数徽标 |
| 星标邮件 | 用户手动标星的邮件 |
| 已发送 | 用户发出的邮件 |
| 草稿箱 | 显示草稿数徽标 |
| 垃圾邮件 | 被识别为垃圾的邮件 |
| 已删除 | 软删除的邮件 |

**AI 助手区域：**

| 导航项 | 说明 |
|--------|------|
| 个人日程 | 切换为日历全宽视图 |
| 工作流程 | 切换为工作流编辑器 |
| AI 对话 | 切换为全宽 AI 对话视图 |
| 通讯录 | 切换为通讯录全宽视图 |

#### 3.2.2 邮件列表展示

每封邮件条目显示：
- 发件人名称
- 发送时间（相对时间：刚刚 / N分钟前 / N小时前 / N天前 / 具体日期）
- 邮件主题
- 正文预览（前100字）
- 标签（星标、工作、紧急等）
- 未读状态（视觉高亮）
- 当前选中状态

#### 3.2.3 搜索

- 搜索框位于列表顶部
- 实时过滤（输入即搜索）
- 搜索范围：主题、发件人、正文预览
- 快捷键：`Ctrl/Cmd + K` 聚焦搜索框

#### 3.2.4 列表工具栏

- 刷新按钮：重新拉取邮件
- 筛选按钮：按条件过滤（未读/已读/有附件等）
- 排序按钮：按时间/发件人/主题排序

---

### 3.3 邮件详情

#### 3.3.1 邮件头部信息

- 邮件主题（大字显示）
- 发件人头像（姓名首字母）
- 发件人姓名 + 邮箱地址
- 收件人邮箱
- 完整发送时间

#### 3.3.2 操作工具栏

| 操作 | 说明 |
|------|------|
| 上一封 / 下一封 | 在当前文件夹内导航 |
| 回复 | 打开写信窗口，预填收件人和主题 `Re:` |
| 全部回复 | 回复所有收件人 |
| 转发 | 打开写信窗口，预填主题 `Fwd:` 和正文引用 |
| 星标 | 切换星标状态，图标变为金色 |
| 删除 | 移至已删除文件夹 |
| 更多 | 下拉菜单（标记未读、移动到等） |

#### 3.3.3 AI 摘要卡片

- 在邮件正文上方展示
- 以要点列表形式呈现邮件核心内容（3-5条）
- 支持手动重新生成
- 可通过设置全局开关控制是否自动生成

#### 3.3.4 附件

- 显示附件文件名和大小
- 支持下载附件
- 常见格式图标区分（PDF、Word、图片等）

#### 3.3.5 AI 操作栏

位于邮件正文下方，提供以下 AI 快捷操作：

| 按钮 | 功能 |
|------|------|
| 智能回复 | 打开弹窗，展示 AI 生成的多种回复草案 |
| 生成摘要 | 重新生成并展示 AI 摘要 |
| 翻译 | 将邮件正文翻译为目标语言 |
| 提取任务 | 从邮件中识别待办事项并列出 |

---

### 3.4 写信（Compose）

#### 3.4.1 写信窗口

- 以浮动模态框形式呈现
- 支持最小化 / 最大化 / 关闭
- 表单字段：
  - 收件人（支持多个，逗号分隔）
  - 抄送（可展开）
  - 密送（可展开）
  - 邮件主题

#### 3.4.2 富文本编辑器（Tiptap）

支持以下格式化功能：
- **加粗** / *斜体* / 下划线
- 无序列表 / 有序列表
- 插入链接
- 附件上传

#### 3.4.3 AI 写作助手（可折叠面板）

**快捷操作按钮：**

| 按钮 | 功能 |
|------|------|
| 生成草稿 | 根据当前输入内容生成完整邮件 |
| 改进写作 | 优化现有正文的语言表达 |
| 精简内容 | 缩短邮件，去除冗余 |
| 更加正式 | 将口语化表达调整为正式商务风格 |

**自由提示输入框：**
- 用户描述想写的内容
- AI 生成对应的邮件正文填入编辑器

#### 3.4.4 发送与草稿

- 发送：验证收件人非空，发送后关闭窗口并添加至已发送
- 保存草稿：保存至草稿箱，可继续编辑
- 快捷键：`Ctrl/Cmd + N` 打开写信窗口

---

### 3.5 智能回复

- 点击邮件详情中的「智能回复」按钮触发
- 弹出模态框，展示 AI 生成的多种回复建议
- 每条建议包含：
  - 类型标签（确认、提问、简短回复等）
  - 回复正文预览
- 点击任一建议：关闭弹窗 → 打开写信窗口 → 预填该建议内容

---

### 3.6 AI 智能分类（标签）

侧边栏「AI 智能分类」区域展示标签：

| 标签 | 颜色 |
|------|------|
| 紧急 | 红色 |
| 工作 | 蓝色 |
| 个人 | 绿色 |
| 财务 | 黄色 |

- 点击标签过滤对应邮件
- 支持添加自定义标签
- AI 自动为新邮件打标签（后端能力）

### 3.7 个人日程（日历视图）

点击侧边栏「个人日程」后，主内容区切换为全宽日历视图。

#### 3.7.1 日历展示

- 月视图，7列网格
- 显示当月 + 相邻月灰色日期
- 今日高亮
- 每个日期格显示当日事务（带颜色标签）
- 月份导航（上一月 / 下一月）

#### 3.7.2 事务管理

**添加事务（点击日期格 或 「添加事务」按钮）：**

| 字段 | 说明 |
|------|------|
| 标题 | 必填 |
| 日期 | 默认点击的日期 |
| 开始时间 | 时间选择器 |
| 结束时间 | 时间选择器 |
| 重复 | 不重复 / 每天 / 每周 / 每月 / 每年 |
| 重复结束日期 | 仅在选择重复时显示 |
| 颜色标签 | 5种颜色可选 |
| 备注 | 多行文本 |

**编辑/删除事务：**
- 点击日历上的事务条目打开编辑模态框
- 编辑模态框额外显示「删除」按钮

**重复事务逻辑：**
- 每天重复：从起始日期之后每天显示
- 每周重复：每周同一天显示
- 每月重复：每月同一日期显示
- 每年重复：每年同一月日显示

点击侧边栏「通讯录」后，主内容区切换为全宽通讯录视图。

#### 3.8.1 通讯录布局

通讯录视图采用**双栏布局**：

#### 3.8.2 联系人信息字段

每个联系人包含以下信息：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 姓名 | TEXT | 是 | 显示名称 |
| 邮箱 | TEXT[] | 是 | 支持多个邮箱地址 |
| 电话 | TEXT[] | 否 | 支持多个电话号码 |
| 公司 | TEXT | 否 | 所属公司/组织 |
| 职位 | TEXT | 否 | 职务/头衔 |
| 分组 | TEXT[] | 否 | 所属分组（支持多分组） |
| 备注 | TEXT | 否 | 多行文本备注 |
| 头像 | TEXT | 否 | 头像图片路径 |
| 星标 | BOOLEAN | 否 | 是否为重要联系人 |
| 创建时间 | INTEGER | 是 | Unix 时间戳 |
| 更新时间 | INTEGER | 是 | Unix 时间戳 |

#### 3.8.3 联系人列表展示

列表视图每条联系人卡片显示：
- 头像（默认显示姓名首字母，彩色背景）
- 姓名
- 主要邮箱地址
- 主要电话号码（如有）
- 公司名称（如有）
- 星标标识（如有）
- 所属分组标签

**列表操作：**
- 点击：查看详情
- 右键：弹出上下文菜单（编辑、删除、发邮件、复制邮箱）
- 拖拽：移动到其他分组

#### 3.8.4 搜索与过滤

**搜索功能：**
- 搜索框位于列表顶部
- 实时搜索（输入即过滤）
- 搜索范围：姓名、邮箱、电话、公司、备注
- 快捷键：`Ctrl/Cmd + K` 聚焦搜索框

**过滤选项：**
- 按分组过滤
- 按星标过滤（只显示星标联系人）
- 按字母索引快速定位

#### 3.8.5 添加/编辑联系人

**新建联系人：**
- 点击「新建联系人」按钮打开模态框
- 表单字段：姓名（必填）、邮箱（必填，可添加多个）、电话、公司、职位、分组、备注
- 表单验证：邮箱格式验证、重复邮箱检测
- 保存后自动返回列表并高亮新联系人

**编辑联系人：**
- 点击联系人卡片进入编辑视图
- 支持修改所有字段
- 修改记录更新时间

#### 3.8.6 分组管理

**默认分组：**
- 全部联系人（虚拟分组，不可删除）
- 未分组（未分配分组的联系人）

**自定义分组：**
- 用户可创建自定义分组（如：合作伙伴、客户、供应商等）
- 分组支持颜色标签
- 分组支持重命名、删除
- 删除分组时，该分组联系人移至「未分组」

**分组操作：**
- 左键点击分组：过滤显示该分组联系人
- 右键点击分组：编辑分组、删除分组
- 拖拽联系人到分组：快速分配

#### 3.8.7 与邮件功能集成

**写信时自动填充：**
- 在写信窗口输入收件人时，自动搜索并提示匹配的联系人
- 提示内容显示：姓名 + 邮箱 + 头像
- 支持键盘上下选择，Enter 确认

**邮件列表显示：**
- 发件人/收件人显示联系人姓名（而非邮箱地址）
- 点击发件人姓名：跳转到联系人详情
- 鼠标悬停发件人：显示联系人卡片预览（姓名、邮箱、电话、公司）

**快捷操作：**
- 右键点击邮件发件人：添加到通讯录、发邮件、查看联系人
- 从邮件创建联系人：自动填充姓名和邮箱

#### 3.8.8 导入/导出

**导入功能：**
- 支持导入 vCard (.vcf) 格式联系人文件
- 支持批量导入
- 导入时检测重复邮箱，询问用户处理方式（跳过/覆盖/合并）

**导出功能：**
- 支持导出单个联系人（vCard 格式）
- 支持导出全部联系人（vCard 格式）
- 支持导出选中联系人

#### 3.8.9 数据同步

**本地存储：**
- 联系人数据存储在 SQLite 数据库
- 支持离线访问

**未来扩展（可选）：**
- 支持与系统通讯录同步（macOS 联系人、Windows Outlook 联系人）
- 支持与 Google 联系人同步
- 支持与 CardDAV 服务器同步

### 3.12 AI 对话框（自然语言邮件助手）

这是 Postium 的**旗舰 AI 功能**，用户可通过自然语言对话的方式查询、操作、管理邮件，无需手动逐一点击。

#### 3.12.1 入口与布局

两种唤出方式：

| 方式 | 说明 |
|------|------|
| 侧边栏「AI 助手」导航项 | 主内容区切换为全宽对话视图 |
| 全局悬浮按钮（右下角） | 以**侧边抽屉**形式从右侧滑出，宽约 400px，不遮挡邮件列表 |

快捷键：`Ctrl/Cmd + /` 打开/关闭 AI 对话抽屉。

对话界面结构：
```
┌─────────────────────────────────┐
│  🤖 Postium AI 助手        [×]  │
├─────────────────────────────────┤
│                                 │
│  [欢迎消息 + 功能提示]            │
│                                 │
│  ┌─────────────────────────┐   │
│  │ AI：已找到 12 封通知邮件  │   │
│  │ 是否全部标为已读？        │   │
│  │ [✓ 确认执行] [✗ 取消]    │   │
│  └─────────────────────────┘   │
│                                 │
│  ┌─────────────────────────┐   │
│  │ 用户：好的               │   │
│  └─────────────────────────┘   │
│                                 │
│  ┌─────────────────────────┐   │
│  │ AI：✅ 已将 12 封通知邮件 │   │
│  │ 标为已读                 │   │
│  └─────────────────────────┘   │
│                                 │
├─────────────────────────────────┤
│  [输入框：询问或下达指令...]  [↑] │
└─────────────────────────────────┘
```

#### 3.12.2 能力分类

AI 对话框支持两大类能力：**查询类**和**操作类**。

**查询类（只读，无需确认）：**

| 示例指令 | 说明 |
|----------|------|
| `上周收到了哪些来自 GitHub 的邮件？` | 按发件人 + 时间范围搜索 |
| `有没有关于项目报告的邮件？` | 语义搜索邮件内容 |
| `我有几封未读邮件？` | 统计查询 |
| `最近有哪些需要我回复的邮件？` | AI 判断待处理邮件 |
| `帮我总结今天的邮件` | 批量摘要 |
| `这封邮件说了什么重点？` | 对当前选中邮件提问 |

**操作类（执行前需用户确认）：**

| 示例指令 | 执行动作 |
|----------|---------|
| `将所有通知类邮件全部标为已读` | 批量 markRead |
| `把 GitHub 的邮件移到工作标签` | 批量 addLabel |
| `删除三个月前的所有促销邮件` | 批量 moveToTrash |
| `把所有未回复的客户邮件标为星标` | 批量 star |
| `帮我回复这封邮件，说明天下午有空` | 生成草稿并打开写信窗口 |
| `给所有来自 boss@company.com 的邮件设为紧急标签` | 批量 addLabel |
| `清空垃圾邮件文件夹` | 批量永久删除 |

#### 3.12.3 交互流程

```
用户输入
    │
    ▼
AI 意图识别（查询 or 操作？影响范围多大？）
    │
    ├─── 查询类 ──► 直接返回结果，以结构化方式展示
    │
    └─── 操作类
              │
              ▼
         AI 解析出操作计划，展示预览：
         "将对 X 封邮件执行 Y 操作，是否确认？"
         附操作摘要（影响邮件列表可预览）
              │
         ┌────┴────┐
         │         │
       确认       取消
         │         │
         ▼         ▼
      执行操作    中止，无副作用
         │
         ▼
      返回执行结果（成功数量、失败项等）
      同步更新邮件列表状态
```

**安全原则：**
- **不可逆操作**（永久删除）需二次确认
- 批量操作超过 **50 封**时额外警告提示
- 所有操作均可在 Toast 中点击「**撤销**」（软删除类操作支持30秒内撤销）

#### 3.12.4 上下文感知

AI 对话具备会话上下文能力：

```
用户：找一下上周 OpenAI 发的邮件
AI：找到 3 封，分别是：[列表]

用户：把它们都加上"工作"标签         ← AI 知道"它们"指上一步的结果
AI：即将为这 3 封邮件添加"工作"标签，确认吗？

用户：顺便把第一封标为星标
AI：已执行，同时为"Introducing GPT-4 Turbo"添加星标。
```

- 会话历史在当前会话内保持
- 支持代词指代（"它们"、"这封"、"上面的"）
- 当前选中的邮件自动作为上下文注入

#### 3.12.5 展示格式

AI 回复支持以下富格式输出（Markdown 渲染）：

| 内容类型 | 展示方式 |
|----------|---------|
| 邮件列表结果 | 可点击的邮件卡片列表（点击可跳转到该邮件） |
| 统计数据 | 数字高亮 + 简洁描述 |

| 邮件摘要 | 要点列表，每条可展开 |
| 错误提示 | 友好说明 + 建议替代操作 |

## 四、UI / 设计规范

### 4.1 设计风格

**Glassmorphism（玻璃拟态）**，深色优先：
- 背景：深色基底 `#0F0F23` + 动态渐变光晕（紫/蓝色调）
- 组件背景：半透明玻璃效果 `rgba(255,255,255,0.05)` + `backdrop-filter: blur`
- 浅色主题同样支持

### 4.2 颜色系统

| Token | 值 | 用途 |
|-------|----|------|
| `--primary` | `#7C3AED` | 品牌主色、按钮、高亮 |
| `--primary-hover` | `#6D28D9` | 主色悬停态 |
| `--secondary` | `#A78BFA` | 辅助色 |
| `--accent` | `#F43F5E` | 警示/危险操作 |
| `--bg-base` | `#0F0F23` | 深色背景底色 |

### 4.3 圆角

全局统一 `8px` 圆角。

### 4.4 字体

- 中英文混排：Inter（英文）+ 系统默认中文字体
- 字重：300 / 400 / 500 / 600 / 700

### 4.5 动效

- 快速过渡：`150ms ease`
- 常规过渡：`200ms ease`
- 慢速过渡：`300ms ease`

## 五、非功能需求

### 5.1 性能

- 邮件列表使用**虚拟滚动**，支持数千封邮件无卡顿
- 初始启动时间 < 2 秒
- AI 操作使用流式输出，响应延迟感知 < 500ms

### 5.2 安全

- 账号密码使用 Tauri 安全存储（操作系统密钥链）
- 邮件本地缓存加密存储
- 不向第三方发送邮件内容（AI 调用需用户授权并可配置本地模型）

### 5.3 离线能力

- 已拉取的邮件本地缓存，断网可查看
- 离线状态下写信可保存草稿
- 状态栏显示离线提示
